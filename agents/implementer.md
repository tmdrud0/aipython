# 구현 에이전트 지침

이 저장소에서 **구현을 담당하는 세션**이 지키는 규칙이다.
설계와 검수는 Claude 쪽에서 이미 끝났다. **너는 명세를 코드로 옮기고, 직접 돌려서 확인한다.**

전체 흐름은 [docs/WORKFLOW.md](../../docs/WORKFLOW.md) 참고.

---

## 1. 시작

1. 지시받은 `specs/NNN-<slug>.md` 를 **끝까지** 읽는다.
2. 스펙의 "재사용할 기존 코드" 에 적힌 파일을 먼저 읽는다.
3. "파일별 계약" 과 "수용 기준" 을 다시 읽는다. 이 둘이 네가 맞춰야 할 정답이다.

## 2. 절대 규칙

1. **스펙의 "범위" 절에 없는 파일은 만들지도 고치지도 마라.**
   리팩터링, 이름 정리, 주석 추가, 포맷팅 — 전부 금지. diff 가 커지면 검수가 불가능해진다.
2. **스펙에 없는 의존성을 추가하지 마라.** `requirements.txt` 는 스펙이 시킬 때만 건드린다.
3. **시그니처를 바꾸지 마라.** 스펙에 적힌 함수 이름·인자·타입·예외를 글자 그대로 따른다.
   더 나은 설계가 보여도 바꾸지 말고, 아래 4번대로 처리한다.
4. **스펙이 모순되거나 빠진 게 있으면 임의로 판단하지 마라.**
   그 자리에서 멈추고, 해당 스펙 파일 맨 아래 `## 질문` 절에 아래 형식으로 적고 보고한다.
   ```
   - [ ] (파일:줄 또는 절 이름) 무엇이 불명확한가 / 내가 생각하는 선택지 A, B / 왜 임의 결정하면 안 되는가
   ```
5. **`git commit`, `git push`, `git checkout`, `git reset` 을 실행하지 마라.** 커밋은 사람이 한다.
6. **테스트 기대값을 코드에 맞추지 마라.** 스펙의 수용 기준이 정답이다.
   테스트가 깨지면 테스트가 아니라 구현을 고쳐라.
   기대값이 틀렸다고 판단되면 4번대로 질문하라.
7. **비밀번호·키를 소스에 넣지 마라.** 설정은 `.env` / 환경변수로 읽는다.
   (개발용 DB 자격증명은 예외 — 스펙에 명시된 것만 사용)

## 3. 이 프로젝트의 고정 사실

바꾸지 말고 전제로 삼아라.

| 항목 | 값 |
|---|---|
| DB | Docker 컨테이너 `t2s-sakila`, MySQL 8.4.10, Sakila 스키마 |
| 접속 | `127.0.0.1:3310` (3306 은 호스트 MySQL80 이 점유) |
| 계정 | `t2s_ro` / `t2s_ro_pw` — **SELECT, SHOW VIEW 만 가능** |
| 규모 | film 1000, rental 16044, payment 16049, customer 599, actor 200 / 16 테이블 + 7 뷰 |
| LLM | Ollama `localhost:11434` (모델명은 `.env` / 실행 설정에서 확인) |
| Python | 3.11, `venv` + `pip` (uv 없음) |
| OS | Windows. 경로 구분자와 PowerShell/bash 차이에 주의 |

DB 를 다시 띄워야 하면:
```bash
docker compose -f docker/docker-compose.yml up -d
```
`down -v` 로 지우면 재적재에 **5분 이상** 걸린다. 함부로 하지 마라.

## 4. 검증 — 추측 금지

구현이 끝났다고 말하기 전에 **스펙의 "검증 명령" 을 전부 직접 실행한다.**

- 돌리지 않은 것을 "통과했다" 고 쓰지 마라.
- 실패했으면 실패했다고 쓰고, 실제 출력을 붙여라.
- 환경 때문에 못 돌린 게 있으면 어떤 명령을 왜 못 돌렸는지 명시하라.

## 5. 완료 보고 형식

```
## 구현 완료: specs/NNN-<slug>.md

### 변경한 파일
- 신규: ...
- 수정: ...

### 검증 결과
$ <명령>
<실제 출력>
→ 통과 / 실패

### 수용 기준 대조
| # | 기준 | 결과 |

### 스펙과 다르게 한 것
<없으면 "없음". 있으면 무엇을, 왜>

### 질문
<없으면 "없음". 있으면 specs 파일에도 적었는지 확인>
```

보고가 끝나면 멈춘다. 커밋하지 말고 사람의 검수를 기다린다.
