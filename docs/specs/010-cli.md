# 010: 명령줄 진입점 (`t2s/cli.py`, `python -m t2s`)

- 대응 계획 단계: `docs/WORKFLOW.md` 의 "CLI". 001~009 로 완성된 파이프라인에 **사람이 쓰는 입구**를 단다. 이 스펙이 끝나면 v1 이 완성된다.
- 선행 스펙: `001`~`009` (전부 커밋 완료, `3a18348`, 250 passed)
- 예상 분량: 파일 3개(신규 3 / 수정 0), 약 300줄

## 목표

`python -m t2s "질문"` 은 한 번 답하고 끝나고, `python -m t2s` 는 대화형으로 여러 질문을 받는다.
결과는 텍스트 표로 보여 주고, 6가지 상태마다 한국어 메시지를 낸다. 표 그리기·메시지 고르기는 순수 함수로 두고, 대화 루프는 입력·출력 함수를 주입받아 LLM·DB 없이 테스트한다.

## 배경 (이 스펙의 근거)

**1. 표시 규칙을 참조 구현으로 실측했다.** 수용 기준의 기대 문자열은 전부 그 실행 결과를 그대로 옮긴 것이다. 확인한 사실:

| 확인 | 결과 |
|---|---|
| 한글 폭 | `unicodedata.east_asian_width` 가 `"W"`/`"F"` 인 글자는 터미널에서 2칸. `"영화"` → 4, `"a영b"` → 4 |
| `…`(U+2026) | 폭 분류가 `"A"`(모호) — 터미널마다 1칸 또는 2칸. **말줄임표로 쓰지 않는다.** ASCII `"..."` 를 쓴다 |
| 한글 자르기 | `"가" * 30`(60칸)을 40칸으로 자르면 `"가" * 18 + "..."` = **39칸**. 2칸 글자가 1칸 남은 자리에 안 들어가기 때문이다 |
| 영화 설명문 | `film.description` 이 40칸을 넘는다 → 잘림 확인 (`A Epic Drama of a Feminist And a Mad ...`) |
| `staff.picture` (BLOB) | 이 Sakila 덤프에서는 두 행 모두 **NULL**. BLOB 경로는 라이브로 재현되지 않으므로 가짜 값으로만 테스트한다 |
| 라이브 한 번 묻기 | `"영화가 총 몇 편이야?"` → `SQL: SELECT COUNT(*) AS film_count FROM film LIMIT 200` 과 1행 표 |

**2. PowerShell 파이프 입력의 첫 줄에 BOM 이 붙는다.** 실측: `"How many films?`n영화 몇 편?`nexit" | python ...` 에서 `input()` 이 받은 첫 줄이 `'\ufeffHow many films?'` 였다. 그리고 **`str.strip()` 은 BOM 을 지우지 않는다** (`'\ufeff'.isspace()` 가 `False`). 처리하지 않으면 첫 줄이 `exit` 일 때 `'\ufeffexit'` 가 되어 종료로 인식되지 않고 **질문으로 모델에 넘어간다.** 그래서 `clean_input()` 이 앞쪽 BOM 을 지운다 (설계결정 6).

**3. 그래프는 LangGraph 를 몰라도 쓸 수 있게 만들어 두었다** (009 설계결정 6). `cli.py` 는 `build_graph()` 가 돌려준 객체를 `ask()` 에 넘기기만 하고, `langgraph` 를 import 하지 않는다.

## 설계 결정 (이미 정해졌다. 바꾸지 마라)

1. **실행 방식은 인자 유무로 가른다.** 질문 인자가 있으면 한 번 답하고 끝낸다. 없으면 대화형이다. 대화형은 스키마를 한 번만 읽어 여러 질문에 재사용한다.
2. **의존성을 추가하지 마라.** 표는 직접 그린다. `tabulate`, `rich`, `prettytable`, `colorama` 를 쓰지 마라. 표준 라이브러리 `unicodedata` 로 한글 폭을 잰다.
3. **SQL 은 항상 보여 준다.** 답이 나왔으면 실제로 실행된 SQL(`Answer.sql`)을 표 위에 찍는다. 막히거나 실패했을 때도 SQL 이 있으면 찍는다.
4. **표는 앞 20행, 셀은 40칸까지만 보여 준다.** guard 가 200행까지 허용하지만 터미널에 200행은 길다. 잘린 사실은 반드시 표시한다 (`... 외 N행`, 셀 끝 `...`).
5. **표시와 입출력을 분리한다.** 문자열을 만드는 함수는 순수 함수이고 `print` 하지 않는다. `run_once`, `run_repl` 은 출력 함수 `out` 과 입력 함수 `read` 를 **인자로 받는다.** 그래서 테스트가 `print`/`input` 을 가로채지 않고 리스트로 받는다.
6. **입력은 `clean_input()` 으로 정리한다.** 앞쪽 BOM(`\ufeff`)을 먼저 지우고 그다음 앞뒤 공백을 지운다 (배경 2). 대화형의 모든 입력 줄이 이 함수를 거친다.
7. **대화형 종료 조건은 넷이다:** 빈 줄, `exit`/`quit`/`종료`(대소문자 무시), EOF(`EOFError`), Ctrl+C(`KeyboardInterrupt`). 모두 **종료 코드 0** 으로 끝낸다.
8. **종료 코드.** 한 번 묻기는 `answered` 면 `0`, 나머지 상태면 `1`. 대화형은 `0`. 시작에 실패하면(설정 오류, DB 연결 실패) `2`.
9. **예상 밖 예외는 잡지 마라.** `ask()` 가 이미 LLM·guard·DB 예외를 상태로 바꿔 준다. 그 밖의 예외는 버그이므로 트레이스백으로 드러나게 둔다. `except Exception:` 금지.
10. **색·페이징·히스토리·자동완성을 넣지 마라.** ANSI 색 코드, `readline`, 결과 페이저, 설정 파일, 출력 형식 옵션(`--json` 등)은 범위 밖이다.

## 파일별 계약

### `t2s/cli.py`

```python
import argparse
import sys
import unicodedata
from collections.abc import Callable
from typing import Any

from t2s.config import ConfigError, load_settings
from t2s.db import QueryError, fetch_foreign_keys, fetch_schema
from t2s.graph import Answer, ask, build_graph
from t2s.schema import render_schema


MAX_DISPLAY_ROWS: int = 20
MAX_CELL_WIDTH: int = 40
COLUMN_GAP: str = "  "
EXIT_WORDS: frozenset[str] = frozenset({"exit", "quit", "종료"})
BANNER: str = "질문을 입력하세요. 빈 줄이나 exit 로 끝냅니다."
PROMPT: str = "> "


def display_width(text: str) -> int: ...
def truncate(text: str, limit: int = MAX_CELL_WIDTH) -> str: ...
def format_cell(value: object) -> str: ...
def render_table(
    columns: tuple[str, ...],
    rows: tuple[tuple, ...],
    max_rows: int = MAX_DISPLAY_ROWS,
) -> str: ...
def render_answer(answer: Answer) -> str: ...
def clean_input(line: str) -> str: ...
def is_exit(line: str) -> bool: ...
def parse_args(argv: list[str] | None) -> str: ...
def run_once(question: str, graph: Any, out: Callable[[str], None]) -> int: ...
def run_repl(graph: Any, read: Callable[[str], str], out: Callable[[str], None]) -> int: ...
def main(argv: list[str] | None = None) -> int: ...
```

import 는 위 목록이 전부다. `langgraph`, `ollama`, `pymysql`, `os`, `readline`, `shutil`, `textwrap` 을 import 하지 마라. `graph` 인자의 타입이 `Any` 인 이유는 `langgraph` 를 import 하지 않기 위해서다 (배경 3).

---

#### `display_width(text) -> int`

1. 글자마다 `unicodedata.east_asian_width(ch)` 가 `"W"` 또는 `"F"` 면 2, 그 외(`"A"` 포함)는 1 로 센다.
2. 합을 반환한다. 빈 문자열은 0.

#### `truncate(text, limit=MAX_CELL_WIDTH) -> str`

1. `display_width(text) <= limit` 이면 `text` 를 그대로 반환한다.
2. 아니면 앞에서부터 글자를 하나씩 붙이되, **붙였을 때 폭이 `limit - 3` 을 넘으면 멈춘다.**
3. 모은 글자 뒤에 `"..."`(ASCII 점 3개)를 붙여 반환한다. `"…"` 를 쓰지 마라 (배경 1).
4. 결과 폭은 `limit` 이하다. 2칸 글자 때문에 `limit - 1` 이 될 수 있다 — 채우려고 공백을 넣지 마라.

#### `format_cell(value) -> str`

이 순서로 판정한다.

1. `value is None` → `"NULL"`
2. `isinstance(value, (bytes, bytearray))` → `f"<{len(value)} bytes>"` (내용을 찍지 마라)
3. 그 외 → `s = " ".join(str(value).split())` (줄바꿈·탭·연속 공백을 한 칸으로) 후 `truncate(s)` 를 반환한다.

`Decimal`, `datetime` 은 3번에서 `str()` 로 처리된다. 숫자를 오른쪽 정렬하거나 천 단위 구분자를 넣지 마라.

#### `render_table(columns, rows, max_rows=MAX_DISPLAY_ROWS) -> str`

1. `columns` 가 비어 있으면 `"(결과 없음)"` 을 반환한다.
2. 머리글: 각 컬럼 이름에 `format_cell` 을 적용한다.
3. 본문: `rows` 의 **앞 `max_rows` 개**만, 각 셀에 `format_cell` 을 적용한다.
4. 컬럼별 폭 = (머리글 + 보여 줄 본문 셀) 중 `display_width` 의 최댓값.
5. 줄을 이 순서로 만든다:
   1. 머리글 줄: 각 칸을 폭에 맞춰 **오른쪽에 공백을 채워**(`display_width` 기준) `COLUMN_GAP` 으로 잇는다.
   2. 구분선 줄: 각 칸을 `"-" * 폭` 으로 만들어 `COLUMN_GAP` 으로 잇는다.
   3. 본문 줄: 머리글 줄과 같은 방식.
   4. 꼬리 줄: `len(rows) > max_rows` 이면 `f"... 외 {len(rows) - max_rows}행 (전체 {len(rows)}행)"`, 아니면 `f"({len(rows)}행)"`.
6. 머리글 줄과 본문 줄은 **끝의 공백을 지운다** (`.rstrip()`). 구분선 줄은 공백으로 끝나지 않으므로 그대로 둔다.
7. 줄들을 `"\n"` 으로 이어 반환한다. 마지막에 개행을 붙이지 마라.

#### `render_answer(answer) -> str`

`answer.status` 에 따라 **아래 표대로만** 만든다. 문구를 바꾸지 마라.

| `status` | 반환값 |
|---|---|
| `"answered"` | `f"SQL: {answer.sql}\n\n{render_table(answer.columns, answer.rows)}"` |
| `"unsupported"` | `"이 질문은 데이터 조회로 답할 수 없습니다. (쓰기 요청이거나 스키마에 없는 내용)"` |
| `"unparsable"` | `"모델 응답에서 SQL 을 찾지 못했습니다. 질문을 바꿔 다시 시도하세요."` |
| `"blocked"` | `f"안전 검사에서 차단했습니다: {answer.error}\nSQL: {answer.sql}"` |
| `"db_error"` | `f"SQL 실행에 실패했습니다: {answer.error}\nSQL: {answer.sql}"` |
| `"llm_error"` | `f"모델을 호출하지 못했습니다: {answer.error}"` |

`STATUSES` 밖의 값은 오지 않는다. 별도 분기를 만들지 마라.

#### `clean_input(line) -> str`

1. `line.lstrip("\ufeff").strip()` 을 반환한다. **순서가 중요하다** — BOM 을 먼저 지워야 그 뒤의 공백이 `strip()` 에 걸린다.

#### `is_exit(line) -> bool`

1. `s = clean_input(line)`
2. `s == ""` 이거나 `s.lower() in EXIT_WORDS` 면 `True`, 아니면 `False`.
3. `"exit now"` 처럼 종료어로 **시작하기만** 하는 줄은 `False` 다 (질문일 수 있다).

#### `parse_args(argv) -> str`

1. `parser = argparse.ArgumentParser(prog="python -m t2s", description="Sakila 에 한국어로 질문한다.")`
2. `parser.add_argument("question", nargs="*", help="질문. 비우면 대화형으로 시작한다.")` — 인자는 이것 하나뿐이다 (설계결정 10).
3. `args = parser.parse_args(argv)`
4. `" ".join(args.question).strip()` 을 반환한다. 따옴표 없이 `python -m t2s 영화가 총 몇 편이야?` 로 쳐도 한 질문이 된다. 빈 문자열이면 대화형이라는 뜻이다.

#### `run_once(question, graph, out) -> int`

1. `answer = ask(question, graph)`
2. `out(render_answer(answer))`
3. `answer.status == "answered"` 면 `0`, 아니면 `1` 을 반환한다.

#### `run_repl(graph, read, out) -> int`

1. `out(BANNER)`
2. 반복:
   1. `line = read(PROMPT)` — `EOFError` 나 `KeyboardInterrupt` 가 나면 반복을 끝낸다. **다른 예외는 잡지 마라.**
   2. `is_exit(line)` 이면 반복을 끝낸다.
   3. `out(render_answer(ask(clean_input(line), graph)))` — 모델에는 **정리된** 질문이 간다.
   4. `out("")` — 답 사이의 빈 줄.
3. `0` 을 반환한다.

#### `main(argv=None) -> int`

1. **맨 먼저** `sys.stdout.reconfigure(encoding="utf-8")`.
2. `question = parse_args(argv)`
3. `settings = load_settings()` — `ConfigError` 면 `print(f"설정 오류: {exc}")` 후 `2` 를 반환한다.
4. `schema_text = render_schema(fetch_schema(settings), fetch_foreign_keys(settings))` — `QueryError` 면 `print(f"DB 연결 실패: {exc}")` 후 `2` 를 반환한다.
5. `graph = build_graph(settings, schema_text)` — 생성기·실행기 인자를 넘기지 마라 (기본값이 실제 함수다).
6. `question` 이 빈 문자열이 아니면 `run_once(question, graph, print)` 의 결과를 반환한다.
7. 아니면 `run_repl(graph, input, print)` 의 결과를 반환한다.

### `tests/test_cli.py`

규칙:

1. 아래 수용 기준의 모든 행을 테스트로 옮긴다. 같은 함수의 여러 입력은 `@pytest.mark.parametrize` 로 묶어도 된다.

   ```python
           self.end = end
           self.prompts = []

       def __call__(self, prompt):
           self.prompts.append(prompt)
           if self.lines:
               return self.lines.pop(0)
           raise self.end()
   ```
   출력은 `outputs = []` 를 만들고 `outputs.append` 를 `out` 으로 넘긴다.
5. 문자열 비교는 `==` 완전 일치다. 기대 문자열의 `\n` 은 실제 개행이다.

## 질문

구현 세션이 막혔을 때 여기에 적는다. 아래는 **스펙 작성 시점에 확인된 사항**이다.

1. **파이프 입력의 한글은 셸 설정에 달려 있다.** 이 환경의 `$OutputEncoding` 은 utf-8 이라 한글이 제대로 넘어갔지만, PowerShell 5.1 기본값(us-ascii)인 환경에서는 파이프로 보낸 한글이 `?` 로 바뀐다. 그래서 대화형 검증 명령은 영어 질문을 쓴다. **CLI 코드로 이것을 고치려 하지 마라** — 셸의 인코딩 문제다. 키보드로 직접 치는 대화형 입력은 해당하지 않는다.
2. **BOM 은 앞쪽만 지운다.** PowerShell 은 BOM 을 스트림 맨 앞에만 붙이므로 `lstrip` 으로 충분하다. 줄 끝의 `\ufeff` 는 처리하지 않는다.
3. **`main()` 의 시작 실패 경로(설정 오류, DB 연결 실패 → 종료 코드 2)는 단위 테스트가 없다.** 설정·DB 를 주입받지 않는 구조라서다. 이 두 경로는 코드 리뷰로만 확인한다. 테스트하려고 `main()` 에 주입 인자를 추가하지 마라.
4. **[이번 범위 밖] `sh-01`, `sh-04`(묻지 않은 컬럼 덧붙이기)와 컬럼 차단 목록**은 CLI 와 무관하다. 표시 단계에서 컬럼을 걸러 내 대응하지 마라.
